# MatrixCalculator — 矩阵计算器

> CS101 课程大作业 · Python 3 · 所有算法从零实现

## 项目背景与目标

本项目是一个功能完整的矩阵计算器，面向学习线性代数的同学和需要矩阵运算的用户。
用户通过命令行界面输入矩阵数据，即可获得各种矩阵运算的结果。

**解决的问题：** 现有矩阵计算工具要么依赖大型数值库（如 NumPy），要么缺乏交互式体验。
本项目完全使用 Python 标准库实现，所有核心算法从零编写，便于理解算法原理和课程知识的应用。

**已完成功能：**
- 矩阵创建（手动输入、单位矩阵、零矩阵）
- 基本运算：加法、减法、乘法、标量乘法
- 高级运算：转置、行列式、逆矩阵、秩
- 行变换：行阶梯形 (REF)、简化行阶梯形 (RREF)
- 线性方程组求解 (Ax = b)
- LU 分解
- 2×2 矩阵特征值
- 余子式矩阵、伴随矩阵

## 课程知识与核心设计

### 使用的数据结构
- **二维列表 (List[List[Fraction]])**：矩阵的存储结构，支持精确分数运算，避免浮点误差
- **Fraction 类**：Python 标准库的有理数类，保证运算精确性

### 核心算法及选择理由

| 算法 | 实现方式 | 时间复杂度 | 选择理由 |
|:---|:---|:---|:---|
| 矩阵乘法 | 三重循环（优化：跳过零元素） | O(m·n·p) | 基础算法，清晰展示计算过程 |
| 行列式 | 高斯消元 → 上三角 → 对角线积 | O(n³) | 远优于按定义展开的 O(n!) |
| 逆矩阵 | 高斯-约当消元 [A\|I] → [I\|A⁻¹] | O(n³) | 数值稳定，易于实现 |
| 秩 | 行阶梯形中非零行数 | O(n³) | 利用已有的 REF 实现 |
| LU 分解 | Doolittle 方法 | O(n³) | 不选主元，简化实现 |
| 线性方程组 | RREF 增广矩阵 | O(n³) | 通用方法，可判断无解/无穷解 |
| 特征值 (2×2) | 特征方程求根公式 | O(1) | 解析解，精确 |

### 模块划分

```
src/
├── matrix.py       # Matrix 类：数据存储、输入输出、格式化
├── operations.py   # 所有矩阵运算算法
├── cli.py          # 命令行交互界面
└── __init__.py     # 包导出
```

核心逻辑（`operations.py`）与界面（`cli.py`）完全分离，便于后续添加 GUI 或 Web 界面。

## 安装与运行

### 环境要求
- Python 3.8 或更高版本
- 无外部依赖（仅使用标准库）

### 安装步骤
```bash
# 克隆或下载项目
cd MatrixCalculator

# （可选）创建虚拟环境
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows
```

### 运行
```bash
python main.py
```

### 最小使用示例
```
>>> new
  输入矩阵（每行用空格分隔数字，空行结束）:
  > 1 2
  > 3 4
  >
[ 1  2 ]
[ 3  4 ]
>>> det
det = -2
>>> inv
逆矩阵 =
[  -2    1 ]
[ 3/2 -1/2 ]
```

### 边界与异常情况
- 维度不匹配的加法/乘法 → 抛出 `ValueError`
- 非方阵求行列式/逆 → 抛出 `ValueError`
- 奇异矩阵求逆 → 抛出 `ValueError`
- 空矩阵输入 → 抛出 `ValueError`
- 复数特征值 → 抛出 `ValueError`（当前不支持）

## 局限与改进

### 已知局限
1. **特征值**：仅支持 2×2 矩阵，且仅实数特征值
2. **LU 分解**：未实现主元选取，遇到零主元会失败
3. **线性方程组**：仅支持方阵系数矩阵，不支持无穷多解的情况
4. **性能**：纯 Python 实现，大规模矩阵运算较慢
5. **界面**：仅 CLI，无图形界面
