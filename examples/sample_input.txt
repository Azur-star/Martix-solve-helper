# 示例输入与预期输出

## 示例 1：矩阵加法

输入 A:
```
1 2
3 4
```

输入 B:
```
5 6
7 8
```

命令: `add`

预期输出:
```
[  6   8 ]
[ 10  12 ]
```

## 示例 2：矩阵乘法

输入 A:
```
1 2
3 4
```

输入 B:
```
5 6
7 8
```

命令: `mul`

预期输出:
```
[ 19  22 ]
[ 43  50 ]
```

## 示例 3：行列式

输入 A:
```
1 2 3
4 5 6
7 8 0
```

命令: `det`

预期输出:
```
det = 27
```

## 示例 4：逆矩阵

输入 A:
```
1 2
3 4
```

命令: `inv`

预期输出:
```
[  -2    1 ]
[ 3/2 -1/2 ]
```

## 示例 5：解线性方程组

Ax = b，其中:
```
A = [1 2]    b = [ 5]
    [3 4]        [11]
```

命令: `solve`

预期输出:
```
x = [1]
    [2]
```

## 示例 6：LU 分解

输入 A:
```
2 1
4 3
```

命令: `lu`

预期输出:
```
L =
[ 1 0 ]
[ 2 1 ]

U =
[ 2  1 ]
[ 0  1 ]
```
