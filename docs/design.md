### 设计原则

1. **核心逻辑与界面分离**：`operations.py` 不依赖任何 I/O，便于测试和复用
2. **精确计算**：使用 `fractions.Fraction` 避免浮点误差
3. **不可变输入**：`Matrix` 对象创建后数据不可变（通过 `copy()` 创建副本参与运算）

## 算法详解

### 1. 矩阵乘法

三重循环实现，时间复杂度 O(m·n·p)。优化：当 `a[i][k] == 0` 时跳过内层循环。

### 2. 行列式

通过高斯消元将矩阵化为上三角形式，行列式等于对角线元素之积乘以行交换符号因子。
时间复杂度 O(n³)，远优于按定义展开的 O(n!)。

对 2×2 和 3×3 矩阵使用直接公式（Sarrus 法则）避免消元开销。

### 3. 逆矩阵

使用高斯-约当消元法：构造增广矩阵 [A|I]，通过行变换将左半部分化为 I，
右半部分即为 A⁻¹。若左半部分无法化为 I（出现零行），则矩阵不可逆。

### 4. 行阶梯形 (REF) 与简化行阶梯形 (RREF)

REF：使用部分主元选取的高斯消元，只消去主元下方元素。
RREF：在 REF 基础上，归一化每个主元行并消去主元上方元素。

### 5. LU 分解

Doolittle 方法：L 为单位下三角矩阵，U 为上三角矩阵。
通过逐步消去得到。当前实现不含主元选取。

### 6. 线性方程组求解

构造增广矩阵 [A|b]，化为 RREF 后直接读取解。
可检测无解情况（出现 0 = 非零 的行）。

## 数据结构选择

### Fraction vs float

| 特性 | Fraction | float |
|:---|:---|:---|
| 精确性 | 完全精确 | 有舍入误差 |
| 性能 | 较慢 | 较快 |
| 适用场景 | 教学、精确计算 | 大规模数值计算 |

本项目选择 Fraction 以保证结果精确，便于教学验证。

### 二维列表 vs 一维数组

选择二维列表 `List[List[Fraction]]`，原因：
- 直观，与数学表示一致
- 访问 `m.data[i][j]` 语义清晰
- 对于教学项目，可读性优先于缓存局部性优化

## 复杂度分析

| 运算 | 时间复杂度 | 空间复杂度 |
|:---|:---|:---|
| 加法/减法 | O(mn) | O(mn) |
| 乘法 | O(mnp) | O(mp) |
| 行列式 | O(n³) | O(n²) |
| 逆矩阵 | O(n³) | O(n²) |
| REF/RREF | O(n³) | O(n²) |
| LU 分解 | O(n³) | O(n²) |
| 秩 | O(n³) | O(n²) |
| 解方程 | O(n³) | O(n²) |
